# My Web Portfolio

This is my **web portfolio** built using:

-   [Astro JS](https://astro.build/)\
-   [Tailwind CSS](https://tailwindcss.com/)\
-   [DaisyUI](https://daisyui.com/)

## Features

-   Clean and minimal design\
-   Fully responsive with Tailwind utilities\
-   Styled with DaisyUI components\
-   Optimized for fast performance with Astro

## Sections

1.  Hero Section -- introduction with name, tagline, and call-to-action\
2.  About Me -- short bio and profile image\
3.  Projects -- showcase of selected works in a grid format\
4.  Skills -- list of technical skills with icons\
5.  Resume -- timeline of experience and education\
6.  Testimonials -- client or peer feedback\
7.  Contact -- form and social links\
8.  Footer -- minimal footer with copyright and icons
